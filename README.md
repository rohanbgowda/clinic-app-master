🏥 Clinic Appointment System | MERN Stack

Developed a full-stack Clinic Appointment System using the MERN Stack (MongoDB, Express.js, React.js, and Node.js) with the aim of making appointment booking and clinic management simpler and more efficient.

The application allows patients to view available doctors, explore their specializations, select suitable time slots, and book appointments online through a responsive and user-friendly interface. It also enables doctors and administrators to manage schedules, patient lists, appointment status, and bookings efficiently.

Through this project, I gained hands-on experience in full-stack web development, RESTful APIs, database integration, frontend-backend connectivity, and real-world application development.

Tech Stack: React.js | Node.js | Express.js | MongoDB | REST API

This project strengthened my understanding of the MERN stack and gave me practical experience in building a complete web application from frontend to backend.
